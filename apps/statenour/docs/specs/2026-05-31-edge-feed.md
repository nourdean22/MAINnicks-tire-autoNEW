## Problem / intent
Operator (Nour): the top-ticker is *"my news feed to keep me updated with the newest hottest cleverest info to help me get ahead in all walks of life."* It's **global** (every statenour page, mounted in `(mastery)/layout.tsx`). Today it interleaves real + fake + dead signals into a 55s CSS marquee at 10px. Goal: only **live, decision-changing, grounded** signals, delivered in a form that respects attention and works on his phone.

## What the review changed (the load-bearing findings)
- **Marquee is the wrong form.** On every page it becomes wallpaper (banner-blindness); on a phone it's unreadable (10px scrolling) and untappable (pause/dismiss are `:hover`-gated → dead on touch). → **kill the marquee.**
- **The AI-ranking cron doesn't earn its place (v1).** `createStructuredAiResponse` bypasses the budget guard (`assertWithinBudget` only wraps `tracedAiChat`) + the cost dashboard + can resolve to a $15-75/1M model via `getModel()`. And LLM 0-10 headline scoring is poorly calibrated — likely no signal over recency×source-weight. → **deterministic rank in v1; AI is a guarded v2 maybe.**
- **The industry RSS pipeline already exists but is dead.** `lib/automotive/industry-monitor.ts` + `industry-sources.ts` feed `BrainMemory(industry_intel)`, consumed by `system-prompt.ts`/`plan-day`/`/intel` — but the `industry-pull` feeder cron was deleted in Wave AE. Half the sources are dead/paywalled (NHTSA recalls, Tire Business, Modern Tire Dealer). → **re-wire the feeder + re-probe sources FIRST.**
- **Relationships ("Dania 14d silent") is the highest-blast-radius item** — sensitive name on every page, wrong-context ambush, and the signal (regex over chat mentions) is near-noise. → **DROPPED entirely** (operator decision 2026-05-31 — the signal is too blunt to trust; revisit only with a real signal).

## Design v1.0

### Form — one item, not a marquee
- Global strip renders **ONE highest-priority item at a time**, static, **≥13px**, **≥44px** tap target, **fade**-advance every ~10s (motion only on change, not continuous scroll), with a **visible** (not hover-gated) dismiss + snooze.
- The **full ranked feed** opens behind one tap (a sheet/panel) — the strip is the headline, the sheet is the read.
- Mobile: identical one-item model (no marquee), tap-to-open, tap-to-snooze.

### Content — lanes, all from confirmed-live sources
- **WORLD:** Market (Stooq — fix weekend/NaN, show session state + real timestamp) · Industry (revived `industry-monitor` after re-wiring the feeder + pruning to live sources) · Tech/AI (a live source — HN top via Algolia API and/or the existing OpenAI/HF blog feeds). *Weather deferred to v2 (no impl; dead precedent).*
- **YOU:** Shop (nickstire bridge — revenue/leads/callbacks ✓) · **Mastery (NEW** — Ambition Engine goal/stat momentum: XP gained today, closest-to-level, stalled goals) · Body/Reflection (**re-sourced** to daily-reflection, not the retired score) · Brain (contradictions/identity/nudges ✓). *(Relationships lane DROPPED — see D-REL.)*

### Ranking — "clever" without per-tick AI
- Deterministic: **source-weight × recency**, + a **why-clause** per item ("X → for you, Y"), + **page-context soft-boost** (shop-first on /money, mastery-first on /stats).
- **Urgent internal items always override to the top, globally** (urgent lead, P0 contradiction) — page emphasis reorders the calm middle, never buries the fire.
- **Relevance floor:** if nothing clears "would change a decision," show fewer items (even zero world items) — *better empty than generic filler* (inherits the repo's ZERO-stale-fallback discipline).

### Calm — decay/snooze, not just dismiss
- Internal "open-obligation" items (contradictions, overdue, relationship) de-escalate after being seen N times without action; **snooze (24h) ≠ dismiss (gone)**; dismiss of live/recurring items (market, shop) is a **today-mute**, not permanent (current id-based forever-dismiss silently loses live lanes).

### Grounding + health
- Every item carries source + href + timestamp. A **dead source is visible** (a lane-health signal), not silently omitted — so "calm" is distinguishable from "dead."

## Constraints (baked in — from the Guardian, non-negotiable)
- **Any new cron = `inngest: true`** with its own `src/inngest/functions/*` (only path to sub-hourly; else `check:crons` [6/6] fails the pre-push gate). Mirror `cron-heartbeat`.
- **All outbound fetches:** `withTimeout`/`AbortSignal.timeout(3-5s)` + **`Promise.allSettled`** (not `Promise.all` — the fan-out-starvation lesson).
- **World feed persisted to Postgres** (BrainMemory-style row, like `industry_intel`) — multi-instance safe (Redis is optional in this repo; L1 cache is per-instance so a cron write wouldn't reach web dynos).
- **Read path stays AI-free + cached**, `retry:false`, top-N ≤ ~15 (the strip is already cheap — preserve it).
- **If AI-curation is added (v2 only):** `tracedAiChat` + `trackGeneration` + **pinned `gpt-4o-mini`** + **themes/categories only (no PII** — no net-worth, exact stats, or reflection text) + prefer the Venice tier.
