# Vapi report contract

## 1. Executive signal
Summarize material call-quality, conversion, reliability, and cost findings.

## 2. Data coverage
State date range, assistant/version, numbers/workflows included, total calls, available outcome fields, and missing downstream data.

## 3. Call funnel
Show attempted, connected, qualified, desired-action attempted, desired-action completed, and downstream success where supported. Never fill absent stages with guesses.

## 4. Reliability and failure table
Rank failure cohorts by business impact, frequency, and avoidable cost. Include ended reasons/tool failures/transfer failures/booking failures/latency or transcript evidence as applicable.

## 5. Conversation quality
Summarize intent recognition, accuracy, naturalness, objection handling, escalation, and representative transcript patterns.

## 6. Economics
Report total cost and unit economics only for metrics with valid denominators.

## 7. Action queue
Use Fix now, Experiment, Watch. Tie each change to a measurable success criterion.

## 8. What would change the conclusion
List missing call outcomes, CRM linkage, booking receipts, version metadata, or other evidence needed.
