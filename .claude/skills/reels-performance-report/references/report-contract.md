# Reels performance report contract

## 1. Executive signal
State the repeatable creative patterns, weak patterns, and major uncertainties.

## 2. Data coverage
Report account, exact dates, number of posts, metric availability, paid/repost exclusions, and cohort metadata completeness.

## 3. KPI distribution
Show reach/plays, retention/watch metrics, shares/sends, saves, profile visits, follows, and downstream outcomes where available. Prefer medians plus totals for skewed metrics.

## 4. Cohort table
Compare formats/topics/hooks/durations/footage types/structure patterns with sample size and normalized rates.

## 5. Creative findings
Explain hook, pacing, information density, payoff, local relevance, and branding patterns supported by the data.

## 6. False wins and failure modes
Call out shallow reach, outlier dependence, low-value virality, weak follower conversion, or local-relevance problems.

## 7. Production queue
Use Scale, Iterate, Pause/Retire. Require a measurable test condition for anything not yet proven.

## 8. What would change the conclusion
List missing retention, local reach, cohort metadata, or downstream conversion evidence.
