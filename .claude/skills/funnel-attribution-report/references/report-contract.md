# Funnel attribution report contract

## 1. Executive signal
State whether the funnel is measurable, where the largest leakage exists, and which reported numbers are trustworthy or questionable.

## 2. System map
Show systems, stage ownership, identifiers, date/time definitions, and source-of-truth status.

## 3. Reconciliation table
Compare adjacent stages with raw counts, joinable counts, unexplained gaps, and known reasons for expected differences.

## 4. Tracking defects
Rank defects by business impact and how much they distort decisions.

## 5. Operational leakage
Separate actual customer loss from instrumentation loss.

## 6. Attribution confidence
Classify key channels/events as deterministic, modeled/probabilistic, partial, or unknown. Do not create an overall score unless the user explicitly supplies one and it is non-political.

## 7. Action queue
Use Repair measurement, Repair operations, Improve later. Include a verification receipt for each repair.

## 8. What would change the conclusion
List missing identifiers, event receipts, CRM fields, or revenue joins that matter most.
