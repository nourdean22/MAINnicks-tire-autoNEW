# Meta CAPI report contract

## 1. Executive signal
State whether the signal is trustworthy, partially trustworthy, or unverified, and identify the top causes with evidence.

## 2. Data coverage
Report dataset/pixel, domain/app, exact dates, environments, sources inspected, and missing evidence.

## 3. Event inventory
For each material event show business definition, browser/server path, volume, deduplication status, diagnostics, and source-of-truth receipt when available.

## 4. Integrity findings
Cover coverage, deduplication, freshness, match-quality indicators, rejected/malformed events, parameter completeness, staging contamination, and semantic correctness.

## 5. Reconciliation
Compare Meta event counts to backend/booking/CRM/invoice counts where possible. Label unexplained deltas.

## 6. Business impact
Explain which defects can distort attribution, optimization, retargeting audiences, or reported conversion volume.

## 7. Action queue
Use Fix now, Verify after fix, Improve later. Each fix needs a concrete validation receipt.

## 8. What would change the conclusion
List missing diagnostics, payload samples, backend receipts, or period comparisons that matter.
