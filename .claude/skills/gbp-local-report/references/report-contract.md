# GBP local report contract

## 1. Executive signal
Summarize material changes in local visibility, customer actions, reputation, and business impact.

## 2. Data coverage
State location, exact dates, available GBP metrics, public-profile evidence, rank-grid/review sources, and missing data.

## 3. Local-demand scoreboard
Show discovery indicators, calls, directions, website clicks, bookings/actions, and review metrics with valid comparisons.

## 4. Search-intent map
Group search terms into brand, tire/product, service, symptom/problem, and location intent when data exists.

## 5. Reputation findings
Report review velocity, rating mix, recurring themes, severe issues, and response gaps without over-weighting isolated reviews.

## 6. Profile and local-visibility opportunities
Prioritize evidence-backed changes to categories, services, content, links, hours, photos, reviews, or local landing support.

## 7. Action queue
Use Do now, Test next, Watch. Include the metric that should validate each change.

## 8. What would change the conclusion
List missing action data, rank grids, downstream lead joins, competitor evidence, or longer history that matters.
