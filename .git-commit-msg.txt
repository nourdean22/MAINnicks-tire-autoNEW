=== CRITICAL FIX (the rest of this wave doesn't matter if this isn't pushed first) ===

server/_core/redirects.ts:
Found a P1 deploy issue verifying wave-181.7 went live as Googlebot:

  /tire-repair-cleveland → HTTP 301 → /tires
  /wheel-alignment-cleveland → HTTP 301 → /tires

The new SERP-fix pages from wave-181.7 were being 301-redirected to
/tires by hardcoded rules in server/_core/redirects.ts that predated
the new pages. Bot HTML response was 40 bytes ("Moved Permanently.
Redirecting to /tires") instead of the 158KB and 159KB real pages.

Removed both redirects (commented with reason · so the audit trail
shows the intent change). The /brake-repair-cleveland → /brakes
redirect STAYS because /brakes still owns that slot (no separate page
was built for /brake-repair-cleveland per the wave-181.7 decision).

Without this fix, wave-181.7's two new pages would have ZERO SEO
value despite all the prerendered HTML — Google would have followed
the 301 and dropped the new pages from its index.
