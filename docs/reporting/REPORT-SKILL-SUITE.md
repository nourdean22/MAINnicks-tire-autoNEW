# Nour report skill suite

Nine independent ChatGPT skills. Install/upload each `skill.zip` separately.

| Skill | Best use | Sensible cadence |
| --- | --- | --- |
| gsc-opportunity-report | Search Console SEO and demand opportunities | Monthly, plus after major SEO/site changes |
| gbp-local-report | Google Business Profile, Maps actions, reviews, local visibility | Monthly |
| vapi-call-ops-report | Voice-agent call quality, conversion, failures, latency, cost | Weekly or monthly, plus after prompt/model changes |
| meta-capi-health-report | Meta Pixel/CAPI event integrity and diagnostics | Monthly, plus after tracking/deploy changes |
| nicks-demand-report | Executive cross-channel demand and business-growth view | Monthly/quarterly |
| funnel-attribution-report | Cross-system funnel reconciliation and attribution integrity | Quarterly, plus after instrumentation changes |
| reels-performance-report | Reels cohorts, retention, shares, followers, local/business impact | Every 2-4 weeks |
| shop-retention-report | Repeat customers, declined work, dormant cohorts, shop economics | Monthly/quarterly |
| production-health-report | Live apps, Railway, Neon, GitHub, CI, jobs, built-vs-working reality | Monthly, plus after major architecture/deploy work |

All skills inspect the current schema/evidence instead of hard-coding platform fields that can drift.
