# antislop audit 001 · 2026-10-10

Scope: the "Prompt experiment" card in the admin VAPI panel
(`apps/nickstire/client/src/pages/admin/settings/VapiPanel.tsx`, the block marked
RECEPTIONIST PROMPT EXPERIMENT and the `PromptExperimentResult` helper).
Mode: after (audit). Nothing was modified. Pick the numbers to fix.

Priority follows the rule tier: Hard Gate = HIGH, Purpose-Gate = MEDIUM, Quality Lock = LOW.

## Findings

1. **HIGH · R-27 UI states.** The status query has no loading or error view. While `promptEvolutionStatus` loads, the card shows only its header and button; if the query itself fails (network, session), the card stays blank with no message. Only the server-side "latest row unavailable" case is handled. Fix: one line "Loading experiment status" while `isLoading`, one line naming the failure when `isError`.
2. **HIGH · R-25 contrast.** The eight-character hash tags use `text-foreground/40` at 10-11 px. On the dark theme that is #F5F5F5 at 40 percent over #0A0A0A, about #686868: contrast 3.6:1, under the 4.5:1 floor for small text. `text-foreground/50` (about #808080, 5.0:1) and darker pass. Fix: raise the hash tags to `/50` or higher.
3. **MEDIUM · R-04 icons.** The run button carries the Lucide `Zap` (lightning) glyph, a listed generic-AI icon, and it is also the "create assistant" icon on the same panel. Relevance to "run an offline experiment" is weak and no reason was written. Fix: drop the icon (the spinner already marks the running state), or use `Play` with the reason "starts a run".

## Checked and kept, with the reason written (R-31)

- Uppercase, wide-tracked 10 px section label "Prompt experiment": every section header on this panel uses that treatment; consistency with the existing admin typography is the reason (R-06).
- Verdict sentences and the CTA "RUN EXPERIMENT NOW" are specific to the action; no buzzwords, no em dashes (R-02, R-15, R-16).
- Chips and header wrap with `flex-wrap`; the button is a 48 px target; long invariant lists wrap at commas (R-03).
- Keyboard: the global `:focus-visible` outline in `index.css` applies to the button (R-32).
- Motion is the spinner only (R-19). Palette is the panel's own tokens plus one primary accent on the button (R-29).
- Three states for the latest row: ok, empty ("No experiment recorded yet"), unavailable ("unknown, not empty") (R-27, server side).
